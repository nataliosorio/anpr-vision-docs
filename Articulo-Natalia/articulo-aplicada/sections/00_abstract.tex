El incremento en el tráfico vehicular y la ineficiencia en la gestión de estacionamientos demandan soluciones tecnológicas robustas para la movilidad urbana inteligente. Para abordar estos desafíos, se presenta un **Sistema de Reconocimiento Automático de Matrículas (ANPR/ALPR)** diseñado para la gestión integral de parqueaderos urbanos. El sistema se basa en un *stack* de código abierto y escalable que combina **Python** con **OpenCV** y modelos de **Deep Learning**.

Específicamente, se utiliza la arquitectura **YOLOv5** para la detección precisa de vehículos y matrículas en tiempo real. El reconocimiento de caracteres se implementa mediante **EasyOCR**, optimizando la robustez ante diversas condiciones de imagen. La arquitectura de comunicación se fundamenta en un flujo de datos asíncrono y de baja latencia, utilizando **Apache Kafka** para el procesamiento de *streams* y **WebSockets/SignalR** para la interacción en tiempo real con la interfaz de usuario.

El sistema fue validado en un entorno de prueba, demostrando no solo una **alta precisión** en la lectura de matrículas, sino también una **gestión eficiente** del estado de ocupación de los espacios. La integración de **ByteTracker** mejora la trazabilidad vehicular. Esta solución ofrece una plataforma adaptable para sistemas de transporte inteligente (ITS), facilitando el control de accesos, el cálculo dinámico de tarifas y la reducción significativa de la congestión en la búsqueda de estacionamiento.

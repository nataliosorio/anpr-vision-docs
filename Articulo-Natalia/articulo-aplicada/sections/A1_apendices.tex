\subsection{Checklist de Reproducibilidad}
Para garantizar la transferencia y la validez externa de los hallazgos de proceso y la arquitectura propuesta, se proporciona el siguiente checklist de reproducibilidad.

\begin{itemize}[leftmargin=*]
  \item \textbf{Datos}: Fuente (ej. Colección de imágenes de parqueos urbanos y datasets públicos como COCO/PASCAL VOC para YOLOv5), versión, licencias (ej. Creative Commons para imágenes públicas), protocolo de anonimización (ej. anonimización de matrículas no estándar).
  \item \textbf{Código}: Repositorio Git (URL), *commit hash* específico de la versión final del artículo, instrucciones detalladas de ejecución (incluyendo el uso de \texttt{Docker-compose.yaml}).
  \item \textbf{Entorno}: Sistema Operativo (ej. Ubuntu 20.04), versión de compiladores (ej. Python 3.9), dependencias principales (\texttt{requirements.txt}), semillas usadas para entrenamiento (si aplica) o configuración base de \texttt{Apache Kafka}.
  \item \textbf{Procedimiento}: Pasos exactos documentados en el \textit{runbook} de adopción (referenciado en \texttt{README.md}) para replicar el entorno de despliegue de los Microservicios.
  \item \textbf{Resultados}: Tablas y figuras que resumen las métricas DORA y de rendimiento (ej. latencia de Kafka) generadas automáticamente en el directorio \texttt{build/}.
\end{itemize}
